# The Top And Flops Mod
A mod for Game Dev Tycoon aimed to give the game a new life. Made in JS and JQuery.

## Features
As of v1.9.5, TT&FM includes:
- Up to 105 new consoles to expand your Game Dev Tycoon experience;
- 70 new researches for your engines;
- 60 new topics with icons;
- 7 brand new genres;
- 30 new random events and over 140 notifications;
- 7 new achievements;
- Custom UI tweaks, dark mode.
